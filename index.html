Pipeline-Global — Fileless, RAG-First Delivery Pipeline

An Orchestrator drives a 5-phase loop (Context → Allocate → Build → Verify → Gate); subagents collaborate over a Redis state bus + shared pgvector RAG and an AST symbol index (toon maps).

Fileless by design — agents share state via Redis + TodoWrite and context via pgvector RAG + an AST symbol index; no files passed between phases.
